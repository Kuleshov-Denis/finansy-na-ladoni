# Мои финансы

Личное приложение для учёта доходов и расходов. Интерфейс адаптирован для телефона и компьютера. Операции сохраняются в локальном хранилище браузера и не отправляются на сервер.

## Запуск

Откройте `index.html` в браузере. Чтобы включить офлайн-режим, запустите `serve.cmd` и перейдите по адресу `http://localhost:4174`. Для установки на телефон разместите папку на HTTPS-хостинге, откройте ссылку в браузере телефона и выберите «Добавить на главный экран».

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub и отправьте в него файлы проекта в ветку `main`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните настройки.
4. После публикации сайт будет доступен по адресу вида `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

GitHub Pages публикует сайт в интернете, поэтому он будет доступен всем, даже если сам репозиторий приватный. На GitHub Free для Pages нужен публичный репозиторий. Подробности — в [официальной инструкции GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Возможности

- добавление доходов и расходов с категорией, датой и комментарием;
- автоматический подсчёт текущего баланса и итогов за месяц;
- история с фильтром по месяцу;
- диаграмма категорий и сравнение последних шести месяцев;
- удаление ошибочной операции;
- офлайн-режим после первого открытия через веб-сервер.

Данные находятся только в браузере, в котором вы добавляли операции. Очистка данных браузера удалит и записи приложения.
